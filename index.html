AIで作る
デジタル手帳

ChatGPTで作って
Etsyに出品するまでの3STEP

絵が描けなくても大丈夫🙌
今回はChatGPTを使って、
「デジタル手帳を作る → Etsyに出品する」
までの流れを3STEPでまとめました。
使うプロンプトもそのまま載せているので、
コピペしながら一緒に作ってみてください✨

  1. STEP 1好きな柄の背景を作る
  2. ↓
  3. STEP 2デジタル手帳にする
  4. ↓
  5. STEP 3Etsyに出品する

STEP 1

好きな柄の背景を作ろう

まずChatGPTを開きます。
デジタル手帳の背景にしたい柄をAIに作ってもらいます。
下のプロンプトをコピーして、[ ] の部分を好きな柄に変えてください。 

Create a seamless, stylish background pattern for a digital planner cover.

Style: [floral / marble / check / botanical / abstract pattern]

Soft, muted colors.
No text, no logos, no people.

Vertical A4 ratio.

柄の例

  • 🌸 floral：花柄
  • 🤍 marble：大理石
  • 🧺 check：チェック
  • 🌿 botanical：ボタニカル
  • 🎨 abstract pattern：抽象柄

色も、beige（ベージュ）・dusty pink（くすみピンク）・sage green（セージグリーン）・light blue（ライトブルー）など、自分の好きな色に変更できます。
「どんな柄にしよう？」と考える時間も、楽しんでみてくださいね✨

STEP 2

背景をデジタル手帳にしよう

STEP1で作った画像をChatGPTにアップロードします。
その画像と一緒に、次のプロンプトを送ります。 

Use the uploaded background image to create a simple and stylish daily planner.

Keep the background design visible.

Add the following sections:

DAILY PLANNER

Date

Today's Top 3

To-do List

Schedule

Notes

Use a clean, easy-to-read layout.

Vertical A4 ratio.

うまくいかないとき

「背景画像は変更せず、そのまま使用してください」と追加で伝えます。

AIで画像を作ると、文字やスペルが崩れることがあります。完成したら必ず文字をチェックしてください。

「記入欄の部分だけ背景を薄くして、文字を書き込みやすくしてください」と追加で伝えます。

他にもこんな手帳が作れるよ

同じ方法で、こんな手帳にもアレンジできます。

まずはDAILY PLANNERを1つ作ってみて、
慣れたらいろいろ試してみよう✨

STEP 3

Etsyに出品してみよう

完成したデジタル手帳はPDFにして、
Etsyなどでデジタル商品として販売できます。

  • 在庫を抱えない
  • 梱包不要
  • 発送不要

PDFにする

ChatGPTに、次のように伝えます。

「このデジタル手帳をA4サイズのPDFにしてください」

Etsyで出品する流れ

  1. Etsyでショップを開設
  2. 商品ページを作る
  3. 商品画像を登録
  4. PDFをアップロード
  5. 価格などを設定して出品

出品前にここだけチェック

  • AIを使って制作した場合は、Etsyの商品説明でAIを使用したことを開示する
  • キャラクター・ブランド・他人の作品などを真似しない
  • AIが生成した文字やスペルを必ず確認する
  • Etsyでは出品料や販売時の手数料が発生する

※Etsyの規約や料金は変更される場合があります。実際に出品するときはEtsy公式の最新情報を確認してください。
